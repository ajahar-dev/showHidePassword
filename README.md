# Show/Hide Password Toggle 🔐

A simple and responsive Show/Hide Password project built using HTML, CSS, and JavaScript.  
Users can toggle password visibility by clicking the eye icon/button.

## Features
- Show/Hide password functionality
- Simple UI
- Responsive design
- Beginner-friendly project

## Technologies Used
- HTML
- CSS
- JavaScript

## Project Structure
```bash
show-hide-password/
│
├── index.html
├── style.css
└── script.js
```

## How It Works
- User enters password
- Click on the eye icon/button
- Password switches between hidden and visible
